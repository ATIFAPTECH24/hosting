# Snip — URL Shortener frontend

1. Backend chalayein (MongoDB on, phir project root mein): `npm install && npm run dev`  (port 8001)
2. Frontend: `cd client && npm install && npm run dev`  → http://localhost:5173

Production mein `VITE_SHORT_BASE=https://your-domain` set karein (short links isi se banenge).
